# Геймплей и баланс AI Agent Survivors

## Основной цикл

```
движение WASD → сбор источников данных → поддержание контекста
→ автоматическое уничтожение ошибок → опыт и уровни
→ выбор улучшений → выживание против растущих волн
```

## Контекст (здоровье)

- Максимум: 100 (пассивка «Расширенное окно»: +22 за уровень).
- Постоянный расход: 0.75/с. Пассивка «Компрессия контекста» снижает расход
  на 18% за уровень (до 28% базового при максимуме).
- Столкновение с врагом: урон типа + масштаб времени, минус броня. После удара
  0.75 с неуязвимости.
- Восстановление: только сбор источников. Каждый тип даёт свою прибавку —
  поддержание контекста остаётся отдельной задачей на протяжении всего забега.

## Источники информации

| Тип | Частота | XP | Контекст | Очки |
|---|---|---|---|---|
| Сниппет | очень часто | 1 | 0.4 | 2 |
| Результат поиска | часто | 2 | 0.7 | 3 |
| Веб-страница | средне | 5 | 2.2 | 6 |
| Ответ API | реже | 8 | 2.0 | 9 |
| Документ PDF | редко | 20 | 7 | 22 |
| Плагин | очень редко | 34 | 9 | 40 |
| Контейнер контекста | ультра-редко | 12 | 28 | 26 |

Элиты гарантированно дают редкий дроп, боссы — плагин или контейнер плюс
шесть страниц. «Магнетрон данных» подтягивает все источники на экране.

## Опыт и уровни

Формула: `XP до уровня N = 11 × 1.235^(N−1) + 4×(N−1)`.
Первые уровни приходят быстро, темп выравнивается к середине забега.

## Оружие

| Оружие | Механика | Эволюция (ур. 8) |
|---|---|---|
| Web Search | самонаводящиеся запросы в ближайшие цели | Deep Research — тяжёлые лучи, ×3 урона |
| Token Stream | поток токенов по направлению движения | Context Overflow — непрерывный поток сквозь врагов |
| Browser Tabs | вращающиеся вкладки с контактным уроном | Multiverse Browser — 8 гигантских вкладок |
| API Calls | цепные разряды с перезарядкой | Gateway — удары каждые 0.7 с, 4 цепи |
| Snippet Storm | веер осколков с пробитием | Kaggle Storm — град из 14 осколков |
| Cache Cleanup | волна урона вокруг агента с отбросом | Garbage Collector — постоянная зона урона |

Пассивки: урон, скорость атаки, скорость снарядов, количество снарядов,
радиус атак, скорость передвижения, максимум контекста, экономия контекста,
радиус сбора, броня, удача.

## Враги

| Тип | Поведение | Особенность |
|---|---|---|
| 404 Not Found | массовый, средняя скорость | базовая пехота |
| 429 Too Many Requests | быстрый, приходят пачками | роятся волнами |
| 403 Forbidden | медленный | высокий запас здоровья |
| 500 Internal Server Error | тяжёлый | взрывается при смерти |
| Timeout | медленный | аура замедления игрока |
| CAPTCHA | средний | при смерти оставляет блоки-препятствия |
| Hallucination | рваные рывки | создаёт ложных фантомов |
| API Failure | держит дистанцию | стреляет снарядами |

Элиты: АРБИТРАТОР РОЯ (гигантский 404 с орбитой мелких) и УТЕЧКА ПАМЯТИ
(медленный, высокий HP, спавнит мелких).

Боссы каждые 3 минуты, циклично с ростом силы:
1. ЯДЕРНАЯ ПАНИКА — площадные удары, спавн 404.
2. ОГРАНИЧИТЕЛЬ ЗАПРОСОВ — быстрые рывки, рой 429.
3. ГЕНЕРАТОР ГАЛЛЮЦИНАЦИЙ — веерные выстрелы и фантомы.

## Сложность

- Скорость спавна: 2.2/с в начале, +2.6/с за каждую минуту (лимит 380 живых).
- Здоровье врагов: +42% за минуту и нелинейный рост на поздних минутах.
- Волны-события каждые ~55 секунд: кольцо противников вокруг игрока.
- Элитные враги появляются после 4-й минуты.

## Очки

- Убийство: базовые очки типа × (1 + время/120).
- Босс: 1500 × множитель цикла.
- Сбор источника: 2–40 очков.
- Время: 2 очка/с. Уровень: +120.

Рекорд (счёт и время) хранится в `localStorage` и показывается в главном меню
и в отчёте после забега.
