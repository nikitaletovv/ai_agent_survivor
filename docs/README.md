# AI Agent Survivors

Сатирическая 2D-игра в жанре survival roguelite по принципам Vampire Survivors.
Карикатурный ИИ-агент выживает в цифровом мире в эстетике «Трона»: контекстное окно
постоянно тает, а со всех сторон наступают HTTP-ошибки — 404, 403, 429, 500, Timeout,
CAPTCHA, Hallucination и API Failure.

Полностью автономный веб-проект: без внешних API, авторизации и сетевых запросов
во время игры. Подходит для любого бесплатного статического хостинга.

## Технологии

- HTML5 + CSS3 + чистый JavaScript (ES2020), без сборки и без зависимостей.
- Рендер: Canvas 2D с неоновой послойной отрисовкой (additive blending).
- Графика: процедурная, генерируется кодом (Canvas + CSS/SVG в интерфейсе).
- Звук: процедурный синтез через Web Audio API (музыка и эффекты генерируются
  во время игры, аудиофайлов нет — см. `docs/ASSETS.md`).
- Сохранения: `localStorage` (личный рекорд и настройки звука).

## Запуск локально

Игра — статический сайт. Любой из способов:

**Вариант 1 — двойной щелчок.** Откройте `index.html` в браузере (Chrome, Firefox,
Edge, Safari последних версий). Скрипты подключены обычными тегами, поэтому
локальный запуск без сервера работает.

**Вариант 2 — локальный сервер (рекомендуется).**

```bash
cd "AI Agent Survivors"
python -m http.server 8000
# откройте http://localhost:8000
```

или, при установленном Node.js:

```bash
npx serve .
```

## Сборка

Сборка не требуется: проект уже в финальном виде. Для минификации можно
использовать любой бандлер (например, `esbuild`), но это опционально:

```bash
npx esbuild js/*.js --bundle --minify --outfile=bundle.js
# затем замените теги <script> в index.html на один <script src="bundle.js">
```

## Размещение на статическом хостинге

Загрузите всё содержимое папки (сохраняя структуру каталогов) в любой
статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages и т.п.

- Точка входа: `index.html`.
- Абсолютных путей в коде нет, работает и из подкаталога.
- Нет запросов к внешним сервисам, поэтому CSP-исключения не нужны.

## Основные правила

- Шкала контекста — это здоровье. Она медленно утекает сама; столкновения с
  ошибками ускоряют потерю. При нуле — конец забега.
- По карте разбросаны источники информации. Зелёные и голубые — частые и мелкие,
  белые PDF, золотые плагины и синие контейнеры контекста — редкие и ценные.
- Убитые ошибки оставляют опыт. Уровень открывает меню выбора одного из трёх
  улучшений: оружие, апгрейды, пассивки и эволюции.
- Оружие до 8 уровня; на 8-м уровне появляется эволюция, меняющая стиль игры.
- Каждые 3 минуты — босс. Периодически — волны-события и элитные противники.
- Цель: выжить как можно дольше и набрать максимум очков. Рекорд сохраняется
  в браузере.

## Тестирование производительности

Игра рассчитана на сотни противников одновременно: пространственная сетка для
коллизий, пулы частиц, отсечение объектов за пределами камеры и автоматическое
снижение плотности эффектов при падении FPS ниже порога (`config.js`,
раздел `performance`).
