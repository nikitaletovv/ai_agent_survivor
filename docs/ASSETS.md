# Ассеты, авторы и лицензии

## Внешние ресурсы

Внешние ресурсы в проекте не используются. Ни одна библиотека, шрифт,
картинка или аудиофайл с внешних площадок не подключается и не загружается
во время игры. Сетевых запросов нет — проект полностью автономен и работает
офлайн.

## Собственные (сгенерированные) ассеты

Вся графика и весь звук созданы для этого проекта программными средствами
и принадлежат автору проекта. Они могут свободно использоваться, изменяться
и распространяться без ограничений (эквивалент лицензии CC0 / Public Domain).

| Ассет | Способ создания | Где описан |
|---|---|---|
| Цифровой мир (сетка, дороги, башни, пилоны, потоки энергии) | процедурная генерация чанков, Canvas 2D, additive blending | `js/world.js` |
| Спрайт героя (ИИ-бот: чип-голова, визор, антенна, индикатор контекста) | векторная отрисовка кодом, анимация ходьбы, свечение | `js/player.js` |
| Спрайты врагов (404, 403, 429, 500, Timeout, CAPTCHA, Hallucination, API Failure, фантомы, элиты, боссы) | векторная отрисовка кодом с пульсацией и хит-флешем | `js/enemies.js` |
| Пикапы (сниппеты, страницы, API-ответы, PDF, плагины, контейнеры контекста) | векторная отрисовка кодом, редкости по цвету и форме | `js/pickups.js` |
| Эффекты (искры, кольца, ударные волны, цифры урона, следы) | система частиц на Canvas | `js/particles.js` |
| Иконки интерфейса | inline SVG, генерируемые функцией `UI.svgIcon` | `js/ui.js` |
| Шрифт интерфейса | системный стек (Segoe UI / Helvetica Neue / Arial), внешние шрифты не загружаются | `css/style.css` |
| Фоновая музыка (синтвейв-луп: бас, кик, хэт, арпеджио с эхом) | генеративный синтез Web Audio, планировщик 16-х долей | `js/audio.js` |
| Звуковые эффекты (выстрелы, попадания, сбор, уровень, босс, взрывы) | синтез осцилляторов и шума в реальном времени | `js/audio.js` |

## Шрифты

Используются только системные шрифты — ограничений по лицензии нет,
дополнительные файлы не требуются.

## Почему не готовые пакеты

Требование проекта — единый визуальный стиль и независимость от сторонних
сервисов. Процедурная графика и синтез звука дают согласованный неоновый
стиль «Трона», нулевой вес проекта (только исходный код) и отсутствие
юридических рисков по лицензиям.
