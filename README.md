# AI Agent Survivors

Сатирическая 2D-игра в жанре survival roguelite по принципам Vampire Survivors.
Карикатурный ИИ-агент выживает в цифровом мире в эстетике «Трона»: контекстное
окно — его здоровье, а со всех сторон наступают HTTP-ошибки — 404, 403, 429, 500,
Timeout, CAPTCHA, Hallucination и API Failure.

Полностью автономный веб-проект: без внешних API, авторизации и сетевых запросов
во время игры. Подходит для любого бесплатного статического хостинга (проект
развёрнут на GitHub Pages).

## Главное меню — чат

Меню — это переписка с AI-агентом (узнаваемым образом: GPT-подобный собеседник).
Первый запуск: агент здоровается, дальше всё зависит от вас — отправьте любой
«тупой» запрос («привет, как дела») и агент, подумав, отправит вас в мир.
История переписки сохраняется в браузере (`aas_history_v1`); после каждого
забега агент в чате отчитывается о результате.

В том же чате — магазин постоянных улучшений: золотые чипы покупок отправляются
как ваши сообщения. Игра копит **данные** за забеги; улучшения показываются
только для контента, с которым вы уже сталкивались. Подробности — `docs/GAMEPLAY.md`.

## Технологии

- HTML5 + CSS3 + чистый JavaScript (ES2020), без сборки и без зависимостей.
- Рендер: Canvas 2D с неоновой послойной отрисовкой (additive blending).
- Графика: процедурная, генерируется кодом (Canvas + CSS/SVG в интерфейсе).
- Звук: процедурный синтез через Web Audio API (музыка и эффекты генерируются
  во время игры, аудиофайлов нет — см. `docs/ASSETS.md`).
- Сохранения: `localStorage` (рекорд, история чата, мета-прогресс, настройки звука).

## Запуск локально

Игра — статический сайт. Любой из способов:

**Вариант 1 — двойной щелчок.** Откройте `index.html` в браузере (Chrome, Firefox,
Edge, Safari последних версий). Скрипты подключены обычными тегами, поэтому
локальный запуск без сервера работает.

**Вариант 2 — локальный сервер (рекомендуется).**

```bash
cd "AI Agent Survivors"
python -m http.server 8000
# откройте http://localhost:8000
```

## Сборка

Сборка не требуется: проект уже в финальном виде. Для минификации можно
использовать любой бандлер (например, `esbuild`), но это опционально.

## Размещение на статическом хостинге

Загрузите всё содержимое папки (сохраняя структуру каталогов) в любой
статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages и т.п.

- Точка входа: `index.html`.
- Абсолютных путей в коде нет, работает и из подкаталога.
- Нет запросов к внешним сервисам, поэтому CSP-исключения не нужны.

## Управление

| Действие | Клавиши |
|---|---|
| Старт забега | отправьте запрос в чате главного меню |
| Движение | `WASD` или стрелки |
| Атаки | автоматические |
| Выбор улучшения | клик мышью или `1` / `2` / `3` |
| Пауза | `Esc` или `P` |
| Музыка вкл/выкл | `M` |
| Покупка улучшения | клик по золотому чипу в чате |

## Основные правила

- Шкала контекста — это здоровье. Постоянного расхода нет: тратится только
  от столкновений с ошибками и выстрелов. При нуле — конец забега.
  Восстанавливается источниками, пассивкой «Context Cache» и подпиской
  «Безлимит Плюс» из мета-магазина.
- По карте разбросаны источники информации; значки под иконками показывают
  их роль: зелёный плюс — контекст, жёлтый ромб — опыт. Магнитится только
  то, что в радиусе подбора — за данными нужно возвращаться.
- Светящиеся шины данных ускоряют всех, кто на них стоит — включая ошибки.
- Убитые ошибки оставляют опыт. Уровень открывает меню выбора одного из трёх
  улучшений: оружие, апгрейды, пассивки и эволюции.
- Оружие до 8 уровня; на 8-м уровне появляется эволюция, меняющая стиль игры.
- Каждые 3 минуты — босс-пародия: «КДЕКС» замораживает спавн и лут, пока жив;
  «СЛАУДФЕЕР» держит ауру «проверки браузера»; «АНТИВОТ» заставляет доказать,
  что вы не робот. Периодически — волны-события и элитные противники.
- Цель: выжить как можно дольше и набрать максимум очков. Рекорд, история
  чата и мета-прогресс сохраняются в браузере.

## Тестирование производительности

Игра рассчитана на сотни противников одновременно: пространственная сетка для
коллизий, пулы частиц, отсечение объектов за пределами камеры и автоматическое
снижение плотности эффектов при падении FPS ниже порога (`config.js`,
раздел `performance`).
